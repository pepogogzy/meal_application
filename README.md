# Recipe App

A Flutter mobile application that provides access to a comprehensive database of recipes through TheMealDB API. The app features recipe browsing by categories, search functionality, and detailed meal information including ingredients and preparation instructions.

## Features

- Browse recipes by categories
- Search for specific meals
- View detailed recipe information
- Clean and intuitive user interface

## API Integration

The application integrates with TheMealDB API to fetch recipe data, including meal categories, search results, and detailed recipe information with ingredients and cooking instructions.
